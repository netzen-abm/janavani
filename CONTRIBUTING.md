# How to Contribute to Janavani

We welcome everyone. No coding needed.

## Ways to Contribute
1.  **Add Office Data**: Add hospitals, panchayats to `database/offices.csv`
2.  **Add Laws**: Suggest new sections for `legal_brain.py`
3.  **Test**: Try to break the bot and report bugs
4.  **Translate**: Add Malayalam/Hindi

## Rules
1.  Be respectful
2.  No fake reviews
3.  Always cite source for data

Contact: Open an Issue
