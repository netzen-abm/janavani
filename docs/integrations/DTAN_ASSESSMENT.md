# DTAN Assessment

Repository: https://github.com/v0l/dtan
Purpose: Distributed Torrent Archive on Nostr (DTAN), described by the repository as a NIP-35 client.

## JanaVani relevance

Potentially relevant as a research/reference pattern for a future decentralized, content-addressed public-data distribution layer. The README describes NIP-35 torrent metadata events and a future relay that clones torrent events from other relays to create additional metadata replicas. This could inform JanaVani's long-term shared-infrastructure/distribution architecture.

## Not suitable for current JanaVani

DTAN is not a civic-case system, legal knowledge source, authority registry, or citizen document workflow. It should not be imported into the current citizen-participation core.

Do not use torrent/NIP-35 distribution for personal or sensitive citizen evidence. Those materials remain on the user's device by design.

## Possible future use

Only for public/non-sensitive datasets and reproducible public knowledge packages, after validating the exact content, licensing, integrity, availability and legal suitability. A future decentralized public-data provider could optionally distribute public dataset metadata or public knowledge snapshots without becoming the source of truth.

## Architectural classification

- Current dependency: NO
- Current integration: NO
- Research/reference: YES
- Future optional shared capability: POSSIBLE
- Private/sensitive evidence storage: NO
