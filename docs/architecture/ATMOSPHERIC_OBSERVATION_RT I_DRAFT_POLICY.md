# Janavani Atmospheric Observatory — RTI Draft Policy

**Status:** Proposed policy
**Related issue:** #175

## Rule

Janavani never submits an RTI application directly. It only generates a reviewable draft for the user.

The user remains the applicant, reviews the content, downloads the document, and submits it independently through the appropriate lawful channel.

## Generation principles

RTI drafts must:

- be generated from a defined evidence gap;
- identify the likely competent public authority;
- request records, documents, permissions, reports, logs or data rather than assert conclusions;
- use a defined date and geographic scope where possible;
- avoid unnecessary personal information;
- avoid unsupported allegations or accusations;
- note that disclosure remains subject to applicable legal exemptions;
- clearly separate observed facts from unanswered questions;
- be editable before export.

## Export

The user may export the final draft as PDF and/or DOCX. No automatic email, postal submission, portal submission or API submission is performed by Janavani.

## Evidence-to-RTI examples

If Janavani has only an aircraft observation:

> Request records establishing whether any authorized aerial operation was conducted in the specified area/time window, without asserting that the observed aircraft performed that operation.

If a public document establishes a cloud-seeding project:

> Request the associated permissions, operational records, aircraft/operator identifiers, dates/areas, reports, monitoring results and related correspondence held by the authority.

If independent observations correlate but causation is unresolved:

> Request records that can establish whether a documented weather-modification activity occurred and what monitoring/evaluation was performed.

## Privacy

Do not automatically insert the user's name, address, phone, email, precise home coordinates or other unnecessary personal information. Where a submission format requires applicant details, leave user-editable placeholders unless the user explicitly supplies them for document generation.
