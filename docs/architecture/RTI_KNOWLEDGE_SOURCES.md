# JanaVani RTI Knowledge Sources

## Source hierarchy

1. Primary law and amendments — India Code / official gazette sources.
2. Applicable official RTI rules and notifications.
3. Official DoPT / Central Information Commission / State Information Commission guidance and procedural material.
4. Verified jurisdiction-specific public-authority information.
5. Verified judicial/commission decisions where legally relevant.
6. Practical guides, including *System Out Complete* by Prasanth Nair IAS, as a clearly labelled practical reference — never as a substitute for primary law.

## Current seed sources

- Right to Information Act, 2005 — India Code: https://www.indiacode.nic.in/handle/123456789/2065?view_type=browse
- RTI Citizen Gateway — Department of Personnel & Training: https://rti.dopt.gov.in/
- *System Out Complete* — Prasanth Nair IAS, Manorama Books: https://subscribe.manoramaonline.com/content/subscription/bookorderdetails.bookscd.SYSOUT.html

## Facebook/social guidance

Public social-media material from Prasanth Nair IAS may be considered as a practical/reference input only when it can be reliably attributed and archived with date/context. It must not be treated as authoritative law. The current implementation does not claim to have ingested or verified a complete Facebook feed.

## Update rule

Legal/procedural knowledge must carry source, jurisdiction and effective-date metadata. A stale source must not silently override a newer verified source. If current applicability cannot be established, JanaVani must say that verification is required rather than inventing a rule.
