# JANAVANI — DOCUMENTATION CORRECTION NOTICE

**Date:** 23 August 2026  
**Status:** LOCKED — CURRENT INTERPRETATION RULE

## Purpose

This notice resolves terminology drift created by earlier audit, planning and release documents written during earlier construction phases.

## 1. PRODUCT SCOPE IS LOCKED

Janavani is being built as a **full citizen-governance ecosystem**.

The ecosystem includes the Dynamic Web, Android, iOS, Telegram Bot, Telegram Mini App, WhatsApp, Messenger, APIs, DApp/Web3 capabilities, and resilient/decentralized capabilities including mesh and satellite pathways where technically and legally supported.

No current document may describe an MVP as the product destination.

## 2. CONSTRUCTION MILESTONE ≠ PRODUCT SCOPE

A bounded implementation target may be used to establish a safe, testable foundation. For example, completing one verified citizen workflow on the Web can be an engineering milestone.

It must be described as a:

> **construction sequence / foundation milestone**

and not as a:

> **MVP destination / final product scope**
