**Status:** ACTIVE — CONSTRUCTION MILESTONE
**Version:** 2.0
**Date:** 23 August 2026
**Scope:** One verified construction milestone inside the complete Janavani ecosystem
**Authority:** Subordinate to `docs/JANAVANI_NORTH_STAR.md`, `docs/JANAVANI_ECOSYSTEM_CHARTER.md`, `docs/SOURCE_OF_TRUTH.md`, `docs/JANAVANI_MASTER_ARCHITECTURE.md`, `ROADMAP.md`, and `docs/MASTER_TASK_CHECKLIST.md`

> **Important:** This document is not an MVP boundary. It is a milestone-level verification checklist. Janavani remains a full citizen-governance ecosystem regardless of the status of this milestone.

## 1. PURPOSE

This checklist verifies a foundational citizen-action workflow while the broader ecosystem is constructed.

The milestone journey is:

```text
Citizen Problem
↓
Issue Understanding
↓
Document Selection
↓
Location / Context
↓
Authority / Office
↓
Identity / User Control
↓
Complaint Construction
↓
Preview / Citizen Approval
↓
Document Generation
↓
Delivery / Download
↓
Tracking / Follow-up foundation
```

This milestone proves a reusable capability foundation. It does not define Janavani's final product scope.

## 2. COMPLETION RULE

A milestone capability is COMPLETE only when applicable evidence exists for:

1. Implementation in the canonical repository path.
2. Integration with the shared platform capability.
3. Automated tests.
4. Functional verification.
5. Security/privacy review where applicable.
6. Repository and deployment verification.
7. Evidence recorded in `docs/MASTER_TASK_CHECKLIST_STATUS_YYYY-MM-DD.md`.

Documentation or source-code presence alone is not completion evidence.
