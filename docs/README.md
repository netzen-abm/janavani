## Rules

- Do not create a new Markdown file until the subject has been searched.
- Prefer extending an existing owner over creating a duplicate.
- Keep canonical architecture separate from dated audit evidence.
- Keep research separate from adopted product requirements.
- Archive superseded material; do not erase history.
- Update links when documents are renamed or moved.
- Never treat documentation presence as implementation evidence.

## One-sentence orientation

**Janavani is one complete citizen-governance ecosystem built from shared infrastructure and reusable capabilities, accessed through independent surfaces, with user control, privacy, safety, provenance and failure isolation as architectural invariants.**
