# SYSTEM DOMAIN MODEL

---

# Purpose

This document defines the core business entities of Janavani.

Every workflow...

Every database table...

Every Python model...

Every AI prompt...

Every API...

must use these definitions.

This document is the shared language of the project.

---

# Core Principle

Janavani is not built around code.

Janavani is built around real-world entities.

Code is only an implementation.

---

Name
