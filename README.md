# JANAVANI 🇮🇳

> Privacy-First Citizen Governance Platform

Janavani is an open-source platform that helps citizens interact with government institutions in a structured, legally informed, and privacy-preserving way.

The goal is simple:

> Help every citizen exercise their constitutional rights without needing legal expertise.

---

# Vision

Build digital public infrastructure that strengthens democracy through:

- Privacy by Design
- Security at the Core
- Open Source
- Citizen First
- Constitutional Governance
- Human-Centered Design

---

# Current MVP

The first MVP focuses on complaint generation.

Citizen Workflow:

```
Describe Issue
        ↓
Select Document
        ↓
Select District
        ↓
Find Office
        ↓
Preview
        ↓
Identity Mode
        ↓
Generate Complaint
        ↓
Download PDF
```
