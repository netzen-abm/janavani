SURFACE INDEPENDENCE
--------------------
WebApp, Telegram, Android, iOS, WhatsApp, Messenger, DApp and future surfaces
are independent consumers. No surface owns a second Case, Evidence, Authority,
Document, Submission, authorization or provider-selection implementation.

SHARED INFRASTRUCTURE SPINE
---------------------------
Identity -> Case -> Evidence -> Authority -> Document -> Review
-> Consent -> Consequential Action -> Submission -> Outcome

SERVICE MIGRATION RULE
----------------------
1. Verify file content and exact callers.
2. Identify one canonical owner.
3. Migrate callers/tests to the canonical contract.
4. Preserve compatibility only while required.
5. Archive before deletion.
6. Delete only after import, runtime, deployment and test evidence is clear.
