# MVP Definition

A citizen should be able to:

1. Describe a government issue.
2. Select a document type.
3. Provide location.
4. Select the correct office.
5. Enter personal details.
6. Generate a professional document.
7. Download or receive the document.

When this workflow is complete and reliable, the Janavani MVP is considered complete.
